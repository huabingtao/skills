# 弹壳攻略文字美化规则

## 1. 数值高亮 (HTML Color)
- **所有匹配的数值与属性增幅** (如星级数量、持续时间、攻击/伤害增益、生命/防御面板等)：统一使用红色加粗。在 HTML 中编译为微信安全的 `<strong><font color="#FF4D4F">数值</font></strong>`。

## 2. 智能图像注入规则 (Image Injection)
- **简写语法（推荐）**：使用双花括号 `{{名称}}` 即可自动展开为行内图标。
  *   **语法**：`{{名称}}`
  *   **示例**：`{{共鸣伤害}}` → 24px行内图标
  *   **适用场景**：行内提及技能、道具、宠物名等需要行内图标的场合
- **转换逻辑**：
  1. 脚本会自动加载 `image_mapping.json`。
  2. 根据“图片名”从字典中检索并替换为对应的真实本地相对路径（如 `assets/img/收藏品/等离子剑.png`）。
  3. 将大括号里的参数转换为对应的微信公众号 inline-css 样式。
- **支持的排版样式类型 (`type=`)**：
  *   `card`：大卡片展示（90% 宽，居中圆角，带阴影）。
  *   `banner`：宽幅海报（100% 宽，居中微圆角）。
  *   `center`：居中展示，支持通过 `w` 自定义宽度（如 `{type=center;w=80%}` 或 `{type=center;w=300}`）。
  *   `grid2`：双栏对比并排（48% 宽，圆角微阴影）。
  *   `grid3`：三栏并排（31.3% 宽，圆角微阴影）。
  *   `grid4`：四栏并排（23% 宽，圆角微阴影）。
  *   `float-left` / `float-right`：图文混排（80px 方形，文字左右环绕）。
  *   `avatar`：角色/宠物头像徽标（30px，行内垂直居中）。
  *   `icon`：普通行内小图标（24px 方形，行内垂直居中）。

## 3. 结构保留原则 (Structural Integrity)
- **严禁改变原文结构**：必须逐字保留用户提供的原始策略文本。
- **严禁转换为列表**：严禁将行内描述（如逗号分隔的属性）转换为无序列表（-）或有序列表（1.）。
- **严禁转换为表格**：严禁将任何文本转换为 Markdown 表格。
- **严禁自作主张换行**：必须保持原有的行内布局，不得在句子中间插入额外的换行符。

## 5. 活动攻略章节图标与排版固化规范 (Section Icon & Formatting Rules)
- **主标题 H2 规范图标**：
  * **基础信息与产出**：`📋 一、 活动基础信息与任务产出明细`
  * **开箱分析**：`📦 二、 开箱节点与道具产出分析`
  * **进度与补钻分析**：`💎 三、 进度消耗与钻石补充分析`
  * **兑换商店推荐**：`🛒 四、 兑换商店推荐`
  * **排行榜与并列**：`🏆 五、 排行榜奖池与并列提示`
- **小章节 H3 与强调块图标**：
  * **产出对照**：`📊 开箱节点与产出对照`
  * **冲刺目标**：`🎯 1. 目标: 达到进度 XX`
  * **说明/提示**：`💡 预估依据说明` / `💡 卡榜与并列提示`
  * **重要警报**：`🚨 周年庆备战提醒`

## 6. 无序列表防折行规范 (Unordered List Line-break Prevention)
- **列表标记与加粗规定**：在 Markdown 列表中，项首标题与说明文字之间统一采用英文半角冒号加空格 `: `，且列表项目头部**严禁**使用 `**` 加粗，以从根本上防止微信公众号移动端渲染时列表项发生意外折行。




## 4. 数字格式与钻石标红规范 (Number Format & Diamond Highlight)
- **数值禁用千位分隔符**：所有数字严格禁用逗号 `,`（例如 `32,888` 必须写作 `32888`），防止导致标红渲染错乱。
- **钻石数值标红**：所有“钻/钻石/{{钻石}}”前面的数值，以及“返钻”后面的数值，统一自动高亮标红（`<font color="#FF4D4F">数值</font>`）。
- **插图默认宽度**：大图与截图居中展示时，默认宽度统一设为 `{type=center; w=80%; caption="..."}`。
