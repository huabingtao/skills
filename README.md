# 弹壳特攻队攻略生成助手 (danke-strategy-skill)

这是一个专为《弹壳特攻队》(Survivor.io) 设计的 **Gemini CLI 技能包**。它能将粗糙的原始游戏攻略转化为排版精美、带自动配图、符合自媒体发布标准的专业推文。

## 🌟 核心功能

### 1. 自动化排版美化
根据 `references/formatting_rules.md` 定义的规则，自动执行：
- **关键词强调**：所有装备、技能名称自动包裹为 `**【关键词】**`。
- **数值高亮**：
  - <font color="#FF4D4F">**攻击/伤害类**</font>数值自动标红。
  - <font color="#1890FF">**生命/防御类**</font>数值自动标蓝。
  - <font color="#52C41A">**范围/冷却类**</font>数值自动标绿。
- **Emoji 注入**：根据内容语义自动在标题和重点前缀 🔥、💎、✅ 等图标。
- **引用块转换**：自动识别提示与警告，转换为标准的提示块（`> [!TIP]`）。

### 2. 智能图像注入
内置 `references/image_mapping.md` 图片映射字典：
- **自动识别**：识别推文中的 SS 装备（如双绝枪、天启战衣）、核心材料（神器核心）等关键词。
- **自动配图**：在关键词后自动插入 `assets/img/` 中对应的 `.webp` 素材路径。

### 3. 表格修饰
- 自动将文本中的数值对比转化为结构化的美化表格。
- 符合 Sentry/专业博客审美标准。

## 🛠️ 维护与扩展

### 更新图片素材
若游戏更新了新装备（如新的 SS 武器）：
1. 将图片放入 `assets/img/`。
2. 在 `references/image_mapping.md` 中添加对应的关键词映射。

### 修改排版规则
修改 `references/formatting_rules.md` 即可改变全量输出的视觉风格（如调整数值颜色代码）。
