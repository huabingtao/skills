# 弹壳特攻队攻略生成助手 (danke-strategy)

本仓库是一个专门为《弹壳特攻队》 (Survivor.io) 攻略博主设计的智能助手技能包。

## 简介
这是一个 **Gemini CLI** (或 Claude Code) 技能插件，旨在自动生成高质量、格式规范、且富有博主风格的游戏攻略。

## 主要功能
- **智能分析**：根据最新的 S/SS 装备数据、宠物选择和配件搭配生成专业点评。
- **神器核心分配**：提供针对 4/16/22/31 核心的多种分配策略建议。
- **模板化输出**：自动遵循“攻略博主”风格排版，包含开场白、置顶图、结构化分析、免责声明等。
- **数据驱动**：集成装备合成表、强化推荐、伤害计算提示等。

## 安装与使用
1. 下载 `danke-strategy.skill` 文件。
2. 将其放入您的 Gemini CLI 技能目录中。
3. 激活技能后，通过命令（如：“写一篇关于SS武器的攻略”）即可开始生成。
