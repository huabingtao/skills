# 弹壳特攻队攻略生成助手 (danke-strategy-skill)

这是一个专为《弹壳特攻队》(Survivor.io) 设计的 **Gemini CLI 技能包**。它不再承担文章“撰写”任务，而是专门作为 **“美化引擎”**，将粗糙的原始攻略转化为排版精美、带自动配图、符合自媒体发布标准的专业推文。

## 🌟 核心功能：全链路排版与发布 (End-to-End Workflow)
专为《弹壳特攻队》攻略提供一键美化排版与微信公众号发布功能。当用户要求“美化”、“排版”或“发布到微信草稿箱”时自动唤醒，接管从 Markdown 格式化、图床上传到自动生成微信草稿的完整工作流。

### 1. 自动化排版美化
根据 `references/formatting_rules.md` 定义的规则，自动执行：
- **关键词强调**：所有装备、技能名称自动包裹为 `**【关键词】**`。
- **数值高亮**：
  - <font color="#FF4D4F">**攻击/伤害类**</font>数值自动标红。
  - <font color="#1890FF">**生命/防御类**</font>数值自动标蓝。
  - <font color="#52C41A">**冷却/范围类**</font>数值自动标绿。

### 2. 智能图像注入
内置 `references/image_mapping.md` 图片映射字典：
- **自动识别**：识别推文中的![占位图:xx]例如![占位图:等离子剑]等关键词。
- **自动配图**：替换![占位图:xx]插入 `assets/img/` 中对应的 `.png` 素材路径。

### 3. 表格修饰
- 自动将文本中的数值对比转化为结构化的美化表格。
- 符合 Sentry/专业博客审美标准。

## 维护与扩展

### 更新图片素材
若游戏更新了新装备（如新的 SS 武器）：
1. 将图片放入 `assets/img/`。
2. 在 `references/image_mapping.md` 中添加对应的关键词映射。

### 修改排版规则
修改 `references/formatting_rules.md` 即可改变全量输出的视觉风格（如调整数值颜色代码）。
