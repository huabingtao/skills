# 弹壳特攻队攻略生成助手 (danke-strategy-skill)

这是一个专为《弹壳特攻队》(Survivor.io) 设计的 **Gemini CLI 技能包**专门作为 **“美化引擎”**，将粗糙的原始攻略转化为排版精美、带自动配图、符合自媒体发布标准的专业推文。

## 🌟 核心功能：全链路排版与发布 (End-to-End Workflow)
专为《弹壳特攻队》攻略提供一键美化排版与微信公众号发布功能。当用户要求“写攻略”、“美化”、“美化攻略”、“优化”、“优化攻略”、“排版”或“发布到微信公众号”时自动唤醒，接管从 Markdown 格式化、图床上传到自动生成微信草稿的完整工作流。

### 1. 自动化排版美化
根据 `references/formatting_rules.md` 定义的规则，自动执行：
- **关键词强调**：所有装备、技能、道具名称自动包裹为 `**【关键词】**`。
- **数值高亮**：
  - <font color="#FF4D4F">**攻击/伤害类**</font>数值自动标红。
  - <font color="#1890FF">**生命/防御类**</font>数值自动标蓝。
  - <font color="#52C41A">**冷却/范围类**</font>数值自动标绿。

### 2. 智能图像注入
内置 `references/image_mapping.md` 图片映射字典：
- **自动识别**：识别推文中的 `[占位图:xx]` 或带参数的 `[占位图:xx|type=grid4|pd=2]`。
- **自动配图**：替换为对应的 `assets/img/` 素材路径，并应用样式参数。
- **高级排版**：
    - `type=grid4`：四宫格布局，支持一排显示 4 张图片。
    - `pd=2`：设置图片内边距（padding）为 2px。
    - **示例**：`[占位图:等离子剑|type=grid4|pd=2]` -> 一排四宫格中的一张，带 2px 边距。

### 3. 表格修饰
- 自动将文本中的数值对比转化为结构化的美化表格。
- 符合 Sentry/专业博客审美标准。

## 目录结构

```text
.
├── SKILL.md                # 技能核心指令集与人设定义
├── GEMINI.md               # 项目上下文与开发规范
├── assets/
│   └── img/                # 游戏素材库 (分类存储)
│       ├── 装备/           # S/SS装备、核心材料
│       ├── 宝箱/           # 各类宝箱、自选礼包
│       ├── 配件/           # 科技配件相关
│       ├── 收藏品/         # 具体收藏品图片
│       ├── 道具/           # 钥匙、碎片、核心、货币
│       ├── 宠物/           # 宠物相关
│       └── 其它/           # 预留目录
├── references/
│   ├── formatting_rules.md # 文本排版与颜色规则
│   └── image_mapping.md    # 关键词 -> 图片路径映射表
└── danke-strategy.skill    # 二进制技能定义文件
```

---

### 更新图片素材
若游戏更新了新装备（如新的 SS 武器）：
1. 将图片放入 `assets/img/`。
2. 在 `references/image_mapping.md` 中添加对应的关键词映射。
