# 弹壳攻略文字美化规则

## 1. 关键词加粗
- **包裹标准**：所有装备、技能、核心道具名称必须包裹在 `**【 】**` 内部。
- **对象范围**：
    - 装备类：如 **【双绝枪】**、**【天启战衣】**。
    - 技能类：如 **【无人机】**、**【雷电发射器】**。
    - 收藏品：如 **【预言塔罗牌】**。
    - 特工/角色：如 **【杨大师】**、**【金】**。

## 2. 数值高亮 (HTML Color)
- **攻击类数值** (攻击、暴击、伤害、增益)：使用红色加粗 `<font color="#FF4D4F">**数值**</font>`。
- **生存类数值** (生命、防御、减伤、回复)：使用蓝色加粗 `<font color="#1890FF">**数值**</font>`。
- **通用/异常类数值** (范围、冷却、持续时间、中毒)：使用绿色加粗 `<font color="#52C41A">**数值**</font>`。

## 3. 智能图像注入规则 (Image Injection)
- **占位符转换与免路径协议**：支持使用标准 Markdown 图片配合 `img://` 协议书写（推荐），或者解析 legacy 占位符 `[占位图：名称]`。
- **推荐语法（Markdown）**：
  `![图片名](img://图片名){type=样式名}`
  *   **示例**：`![等离子剑](img://等离子剑){type=card}`
- **转换逻辑**：
  1. 脚本会自动加载 `references/image_mapping.md`。
  2. 根据“图片名”从字典中检索并替换为对应的真实本地相对路径（如 `assets/img/收藏品/等离子剑.png`）。
  3. 将大括号里的参数转换为对应的微信公众号 inline-css 样式。
- **支持的排版样式类型 (`type=`)**：
  *   `card`：大卡片展示（90% 宽，居中圆角，带阴影）。
  *   `banner`：宽幅海报（100% 宽，居中微圆角）。
  *   `grid2`：双栏对比并排（48% 宽，圆角微阴影）。
  *   `grid3`：三栏并排（31.3% 宽，圆角微阴影）。
  *   `grid4`：四栏并排（23% 宽，圆角微阴影）。
  *   `float-left` / `float-right`：图文混排（80px 方形，文字左右环绕）。
  *   `avatar`：圆形角色/宠物头像徽标（30px 圆形，带深色描边，行内垂直居中）。
  *   `icon`：普通行内小图标（24px 方形，行内垂直居中）。

## 4. 结构保留原则 (Structural Integrity)
- **严禁改变原文结构**：必须逐字保留用户提供的原始策略文本。
- **严禁转换为列表**：严禁将行内描述（如逗号分隔的属性）转换为无序列表（-）或有序列表（1.）。
- **严禁转换为表格**：严禁将任何文本转换为 Markdown 表格。
- **严禁自作主张换行**：必须保持原有的行内布局，不得在句子中间插入额外的换行符。

## 4. 严禁事项 (Prohibited)
- **禁止添加提示标签**：严禁使用 `[!TIP]`、`[!IMPORTANT]`、`[!NOTE]`、`[!WARNING]` 等任何 GitHub 风格的提示或警告框。
- **禁止修改/删减文字**：严禁改写句子、删减语气词或合并段落。仅允许在关键词周围添加加粗、颜色标签或图片。
