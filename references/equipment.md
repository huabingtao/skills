# 弹壳特攻队装备推荐 (Survivor.io Equipment Guide)

## 核心原则
- **增伤词条 > 战力词条**：神铸优先选择增伤属性。
- **解锁 SS 铸造**：首先需要一件红色品质装备。

## SS 级装备梯队
| 部位 | 推荐装备 | 评价与建议 |
| :--- | :--- | :--- |
| **武器** | **双绝枪** | 版本 T0，全能型。建议神 1+0 起步，神 3+2 平民毕业。 |
| **腰带** | **星辰束腰** | 版本 T0。白板属性即可超越神 3 混乱腰带。 |
| **鞋子** | **冰霜战靴** | 轮椅级通用装备。冰缓效果配合收藏品套装加成极强。 |
| **手套** | **月殇护手** | 常驻 30% 暴击率。当前版本暴击收益极高。 |
| **护甲** | **天启战衣** | 上限高。建议 3+0 起步，需提前准备核心。 |

## S 级级过渡推荐
- **武器**：破坏之力（黑洞枪）适合推图；金苦无适合回响远征打 BOSS。
- **项链**：**破坏者徽记（破坏项链）** 优先级极高，建议直接神 3，目前强于 SS 项链。
- **护甲**：亡者之甲（混乱甲）推图挂机神器；永恒战衣前期过渡。
- **腰带**：扭曲腰带（混乱腰带）简单粗暴的增伤。
- **手套**：破坏手套，远征回响表现优秀。

## 毕业配置参考
- **平民目标**：双绝枪(神3+2) + 破坏项链(神3) + 星辰束腰(神3) + 月殇护手(神3) + 冰霜战靴(神1)
