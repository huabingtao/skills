# 神器核心分配策略 (Artifact Core Allocation Strategy)

## 核心强化概念
- **神铸/神炼**：使用 S/SS 装备分解材料（永恒/破坏/混沌之石）+ 神器核心/神炼核心。
- **强化等级表示**：X-X-X（永恒-破坏-混乱）。例如 `3-2-0` 表示永恒 3 级、破坏 2 级、混沌 0 级。

## 各阶段分配方案
| 核心数量 | 推荐搭配 | 目标与效果 |
| :--- | :--- | :--- |
| **4 核心** | **前期重点** | 核心资源极有限，优先强化**永恒**以获得增伤词条。 |
| **16 核心** | **均衡分配** | 建议武器、手套、腰带、鞋子均衡强化为 `1-2` 左右。 |
| **22 核心** | **SS 护甲发力** | 此时核心充足，开始发挥 **SS 天启战衣** 的作用。 |
| **31 核心** | **中后期养成** | 达成 **混乱 6** 核心配置，足以应对绝大部分场景。 |

## 提升建议
1. **优先增伤**：神铸首选增伤词条（如武器、手套、腰带）。
2. **SS 装备门槛**：白板 SS 往往能超越普通神 3 的 S 级装备。
3. **伤害工具**：推荐使用 [Survivor.io 伤害计算器](https://sio-tools.vercel.app/) 进行精准优化。
