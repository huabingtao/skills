# danke-content-creator-skill

专为《弹壳特攻队》游戏攻略打造的内容创作 Skill。分析用户提供的原始素材（活动截图、活动文本、奖励表格、宠物/装备数值等），按照统一的标准 Frontmatter 与模版自动撰写初稿 `攻略.md`。

## 触发词

- "写一篇关于 X 的攻略"
- "根据这些素材生成攻略"
- "撰写活动攻略"
- "分析这个活动素材"
- "生成弹壳攻略.md"

## 职责边界

- **单一职责**：只负责将原始素材转化为结构化的 `攻略.md` 文档。
- **不负责**：HTML 微信编译（由 `danke-strategy-skill` 负责）、切图（由 `article-to-img-skill` 负责）、草稿箱上传（由 publisher skills 负责）。

## 标准 Frontmatter 规范

生成的 `攻略.md` 顶部**必须**包含如下格式的 YAML Frontmatter：

```yaml
---
title: "【活动攻略】活动名称全解析——轻松满奖励策略" # 微信公众号/文章长标题 (≤64字)
social_title: "活动名称全解析！建议收藏"                      # 抖音/小红书短标题 (≤20字，需剥离【...】)
summary: "详细解析弹壳特攻队最新活动的白嫖代币计算、任务优先级、道具兑换顺序与性价比推荐。" # 摘要/描述
tags:
  - 弹壳特攻队
  - 游戏攻略
  - 活动攻略
cover: "./cover.png"                   # 微信横版封面 2.35:1
cover_vertical: "./cover_vertical.png" # 抖音/小红书竖版封面 3:4
author: "弹壳呱呱"
date: YYYY-MM-DD
lastmod: YYYY-MM-DD
---
```

## 写作规范

1. **醒目提示**：在表格计算或代币统计前/后，必须附带：
   > 💡 **温馨提示**：本攻略所有数值计算与代币统计**均未计入看广告获取的额外代币**，玩家可根据自身情况灵活叠加！
2. **结构清晰**：统一按照 `活动概述` → `代币/收益计算` → `兑换优先级` → `氪金/提速建议` → `总结注意事项` 组织结构。
3. **语气风格**：专业且亲切，使用“白嫖”、“T0必兑”、“性价比极高”等玩家熟知的术语。
