# 微信公众号封面图生成器 (WeChat Cover Generator)

## 1. 核心定位 (Scope)
接收一张手机截图（通常是 9:16 的游戏或应用截图），对其进行高清晰度裁切，在中心位置叠加双行或单行的描边与发光阴影文字，生成高颜值的公众号标准封面图（`cover.png`）。支持三种比例布局：横屏（2.35:1）、竖屏（3:4）、方图（1:1）。

## 2. 触发条件 (Triggers)
当用户输入包含以下关键词时自动激活：
- **生成封面**、**制作封面**、**做个封面**、**做封面**、**重新做个封面**、**微信封面**、**公众号封面**、**竖屏封面**、**方图封面**。

## 3. 使用方法与工作流 (Workflow)

1. **识别输入源**：
   - 用户提供活动内截图时，优先选其中清晰的角色、场景和玩法元素作为封面基础。先查看原图；后台数据卡或通用 `article-top` 品牌 Banner 不替代活动封面。需要重排或生成式编辑时使用当前可用的 imagegen；纯裁切叠字可按用户要求使用本技能脚本。
   - 寻找用户给出的图片路径（如 `@[path/to/image.png]` 或 `IMG_xxxx.PNG`）。
   - 寻找用户给出的文字内容，如没有指定，可默认根据文章的 Title 拟定一个（如：`联机挑战\n异宠夺取`）。
   - 寻找用户对文字颜色（如 `金色`、`暖色`、`黄色`）或具体位置的偏好。
   - 识别用户所要求的封面风格（横屏、竖屏、或方图）。
   - 本工作区默认同时交付横版 `dist/cover.png`（2.35:1）与竖版 `dist/cover_vertical.png`（3:4），分别适配布局并使用相同事实与文案；日历横版继续复用共同系列封面。

2. **调用生成脚本**：
   - 运行位于脚本目录下的 `scripts/make_cover.py` 进行图像裁剪和文字渲染。
   - **基础命令行**：
     ```bash
     python3 scripts/make_cover.py -i <输入图片绝对路径> -t "<封面文字>" -o <输出绝对路径> --style <风格>
     ```
   - **参数说明**：
     - `-i / --image`：截图绝对路径（必填）。
     - `-t / --text`：文字内容，支持 `\n` 或空格（` `）作为换行分隔符（必填）。例如 `"弹壳特攻队 周年庆Day6 礼包推荐"` 会自动识别为双行居中文字。
     - `-o / --output`：输出路径，通常是该文章目录下的 `cover.png`。
     - `--color`：文字颜色，Hex格式（如金黄色 `#FFD700`，亮黄色 `#FFCC00`，白色 `#FFFFFF`）。
     - `--style`：封面风格样式，支持 `horizontal`（横屏 2.35:1，默认 900x384）、`vertical`（竖屏 3:4，640x853）、`square`（方形 1:1，500x500）。
     - `--crop-y`：裁切Y轴范围（如 `420-920` ）。若省略则脚本会自动基于行像素方差（Variance）**智能检测视觉重心（最丰富色彩区）**进行自动裁剪。

3. **效果反馈与更新**：
   - 查看并展示横竖封面，检查文字、奖励目标和角色是否清楚，去除黑边、账户资源条等无关区域；不能改造或捏造奖励图标。
   - 用户已要求完整排版发布时，直接同步源码 frontmatter、微信旁注与已授权草稿更新，无需再为常规封面单独确认。只有缺少影响设计的必要信息时才询问。
   - 新增攻略方案不自动要求重做全部封面；封面中的已有事实仍正确时可保留。记录选用原截图与成品路径，素材和验证产物留在文章 `dist/`。
