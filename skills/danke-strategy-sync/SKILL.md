# danke 技能共享链接

原创技能唯一源码在本仓库的 `skills/`。从本技能真实路径向上定位该目录，不依赖当前工作目录或固定用户名。源码修改会通过正确链接即时生效，无需再次复制。

## 执行

1. 先检查源码 Git 状态和目标路径。用户指定目录优先；未指定时默认工作区 `.agents/skills`。
2. 从仓库根目录只读检查：

   ```bash
   python3 skills/danke-strategy-sync/scripts/sync.py
   ```

3. 用户要求修复/同步即已授权创建缺失链接，使用 `--apply`。自定义全局目录使用 `--target-root /明确的/技能目录`。脚本只处理包含 `SKILL.md` 的 `danke-*` 技能。
4. 已正确链接的目标不动。遇到物理目录、错误链接或断链，脚本返回失败且保留原状；比较内容，保存独有修改后才能迁移，不能 `rsync --delete`、`rm -rf` 或覆盖其他技能。
5. 需要测试时加 `--test`，读取实际测试数量和退出码；不写死测试数量，不把未运行称为通过。

Windows 宿主目录需要 Windows 原生目录链接；此脚本用于 WSL/Linux 目标，不把 WSL 中创建的链接视为 Windows 已验证可用。

## 交付

报告已正确、已创建、缺失或冲突的链接，测试是否运行及结果。默认检查发现缺失链接返回 1，完整或成功创建返回 0；异常返回 1。不要把 GitHub 推送和本地链接检查混为一件事。
